One loop

Press. Drag. Paste.

Made for the moment you need to show someone, or an agent, exactly what you are looking at. No dialog, no file, no save step in between.

Press Print Screen

The screen freezes the instant you press it, so open menus and hover states stay put while you choose.

PrtScPrint Screen
or any key you like

Drag an area

The crosshair snaps to window edges, a magnifier shows every pixel, and the size reads out as you go.

Paste it anywhere

It is on the clipboard when you let go. A small preview waits in the corner, and never takes focus.

Everything around the capture

Small things, done properly.

Pins in the top bar

Drag a preview up to the top bar and a shelf drops out to catch it. Your last 15 pins live in a strip in the menu: click to copy again, Alt-click to annotate.

A magnifier that snaps

The selection snaps to window edges, screen edges and the top bar, with guides that turn blue when they catch. Hold Ctrl to place freely; Space switches to picking a whole window.

Drag into any app

Drag a capture into a browser upload, a chat or your file manager, as a PNG named like your saves.

Windows, alone

Click a window to capture just it, with clean rounded corners. Put it on your wallpaper or a colour with a soft shadow.

Copy text from anything

Drag over text in an image, a video or a locked PDF and get it as text. Read on your machine with Tesseract.

Save without asking

Optionally save every capture to a folder of your choice, as PNG or JPEG, with a file name template like %n %Y-%m-%d.

Repeat the last area

Capture exactly the same rectangle again with one key, for before-and-after shots and changing dashboards.

Record when you need to

Shotput takes stills. GNOME's own recorder is one click away in the same menu, and keeps its shortcut.

The editor

Point at the thing.

Press Ctrl+Print and the editor opens right where you captured, as if the screenshot lifted off the screen. Mark it up, press Return, and the result is on your clipboard.

  • AArrow, curve it from the middle
  • NStep numbers that count up
  • RRectangle, filled or not
  • TText, as a label or outline
  • OEllipse, Shift for a circle
  • HHighlighter
  • PPen that turns sketches into shapes
  • BRedact with mosaic or a block
  • LLine, straight or curved
  • CCrop

While Shotput is on, it borrows exactly the Print Screen shortcuts it uses from GNOME's screenshot tool, and hands them back when you turn it off. No Print Screen key on your laptop? Record a function key such as Shift F3; Settings warns you if GNOME already uses it. Mouse software like Solaar or Input Remapper can press any of them from a button.

Under the hood

Native to GNOME, not wrapped around it.

On Wayland only the compositor can freeze the screen, snap to windows and float a preview that never steals focus. So that part of Shotput runs inside GNOME Shell, and the editor is a tiny native app.

~40 MBfor the editor, waiting so it opens instantly

A GNOME Shell extension

Takes the still with screenshot_stage_to_content, draws the selection, the magnifier and the preview, owns the clipboard and the top bar menu, and listens for your keys. Nothing polls.

A Rust and GTK 4 editor

The screenshot is a GPU texture and every mark is a render node with a soft shadow. Export renders the same nodes on the GPU at full resolution, so what you see is what you paste.

Install

One line, no root.

The installer downloads the latest release for your machine from GitHub, checks it, and puts everything in your home folder.

$ curl -fsSL https://shotput.abstergo.fyi/install.sh | bash

Install from a download

Download shotput-linux-x86_64.tar.gz or shotput-linux-aarch64.tar.gz (also on GitHub Releases, with checksums), then:

tar xzf shotput-linux-x86_64.tar.gz
cd shotput-linux-x86_64 && ./install.sh
Build from source

You need Rust and the GTK 4 and libadwaita development packages.

git clone https://github.com/Absterrg0/shotput-linux
cd shotput-linux && ./install.sh
Copy text needs Tesseract

On Fedora the installer sets it up for you, without root. Elsewhere, install it once:

# Debian, Ubuntu
sudo apt install tesseract-ocr
# Arch
sudo pacman -S tesseract tesseract-data-eng
Update or uninstall

Run the install command again to update. To remove Shotput, which also gives GNOME its Print Screen keys back:

curl -fsSL https://shotput.abstergo.fyi/install.sh | bash -s -- --uninstall
Not on GNOME?

The editor and the shotput command still work: shotput area and shotput annotate capture through your desktop's screenshot portal, then open the same editor. The freeze, snapping, preview and pins need GNOME Shell.
